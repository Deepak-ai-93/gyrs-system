# UX Checklist (apply to every page)

- [ ] All nav links work (no `href="#"` on primary actions)
- [ ] Breadcrumb on every inner page (Home / Jobs / Detail)
- [ ] Search / filters actually change results (JS), empty-state message when 0 results
- [ ] Forms: labels, required markers, inline error text, success confirmation
- [ ] Buttons: loading/disabled state where relevant, 44px+ touch target
- [ ] Countdown/last-date shown as "X days left", red when ≤3 days
- [ ] External OJAS links: labeled "Apply on OJAS", `target="_blank"`, external icon
- [ ] Toggles persist via localStorage, state visible on reload
- [ ] Mobile 360px: no horizontal scroll, filters in collapsible panel
- [ ] Footer: disclaimer "Final application on ojas.gujarat.gov.in only", contact, links
- [ ] Gujarati text renders (Noto Sans Gujarati loaded), no tofu boxes
- [ ] Title tag + meta description per page, lang="en" (or "gu" where apt)
